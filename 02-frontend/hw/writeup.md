This week I learned that frontend development is really about building the experience of a site, not just putting info on a website. I liked seeing how quickly you can see the updated website when you run a dev server by changing the file, saving, and the browser updates right away. It made the whole process feel a lot more interactive than what I’m used to. 
With plain HTML and CSS, you’re kind of doing everything and it can get pretty confusing as soon as you have more than one page or want reusable pieces. Next.js gives you a  structure, and it handles a lot of the annoying setup for you (like routing and the build process). It also feels more app-like, even when you’re just making a simple personal site. 
The way TypeScript, Tailwind, and Next.js fit together makes sense now. Next.js is basically the container that runs the site and organizes pages. TypeScript helps catch mistakes early and makes the code feel more solid. Tailwind is just a different way to style, so instead of writing a bunch of custom CSS files, you use classes right in the JSX.
